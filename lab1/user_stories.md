# Користувацькі історії

| ID | Роль | Історія |
|---|---|---|
| US-01 | Покупець | Як покупець, я хочу знайти препарат у наявності за назвою, щоб не телефонувати в кожну аптеку. |
| US-02 | Покупець | Як покупець, я хочу зарезервувати препарат у вибраній аптеці, щоб бути певним, що він мене дочекається. |
| US-03 | Покупець | Як покупець, я хочу скасувати резервування, щоб звільнити товар, якщо план змінився. |
| US-04 | Покупець | Як покупець, я хочу отримати сповіщення про готовність резерву, щоб приїхати вчасно. |
| US-05 | Фармацевт | Як фармацевт, я хочу видавати резерв за кодом, щоб не шукати записи в зошиті. |
| US-06 | Фармацевт | Як фармацевт, я хочу оформлювати продаж за е-рецептом в одній програмі, щоб не вводити дані двічі. |
| US-07 | Завідувач аптеки | Як завідувач аптеки, я хочу реєструвати поставки партій, щоб залишки в системі відповідали полицям. |
| US-08 | Завідувач аптеки | Як завідувач аптеки, я хочу бачити партії, строк придатності яких завершується, щоб вчасно їх реалізувати. |
| US-09 | Директор мережі | Як директор мережі, я хочу отримувати звіт про продажі за період, щоб порівнювати аптеки між собою. |
